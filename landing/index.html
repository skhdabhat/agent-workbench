Start / Agent / MCP Tool / Condition / End 节点，拖拽连线定义任务流。

官方 Filesystem Server + 内置 Fetch，工具列表与调用链一目了然。

执行可观测

SSE 流式日志、节点状态、Function Calling 时间线，Mock 模式免 API Key 演示。

3 分钟演示脚本

  1. 1. 打开在线 Demo，确认 MCP 已连接（Filesystem + Fetch）。
  2. 2. 使用默认 Start → Agent → End，输入「分析某 URL」类任务。
  3. 3. 点击运行，右侧展示 SSE 日志与 Tool Call 链。
  4. 4. 说明 Mock 与真实 LLM 切换、节点重试与 MCP 沙箱目录。
